# Mosquita Muerta · Bajo Cuerda

Juego cooperativo de la cervecería Bajo Cuerda (Pereira). Dos a cuatro moscas amarradas por una cuerda: solo la cuerda recoge cerveza, la sed es compartida y las compuertas se abren con una mosca en cada interruptor.

## Cómo se juega
- **Celular o tablet (acostado):** cada jugador usa su mitad de la pantalla. Arrastrar = volar, toque rápido = zumbido.
- **Computador:** P1 con WASD + Espacio, P2 con flechas + Enter.
- **Controles USB / arcade:** joystick + cualquier botón.

## Archivos
- `index.html`: el juego completo (HTML + JavaScript, sin dependencias).
- `mosca.png`: el isotipo usado en el juego.

## Publicación
Se publica con GitHub Pages desde la rama `main`. Cada cambio que se sube a `main` se publica solo en uno o dos minutos.
